# Мегалюль

Браузерная игра: дрифт на корабле, доставка груза и развитие верфи.

Играть: https://Vlad1slavS.github.io/megalul-game/

Этот репозиторий содержит готовую статическую сборку. Отзывы доступны по кнопке в игре и сохраняются через Google Форму.

Для обновления: собрать проект командой `npm run build` в рабочем репозитории, перенести содержимое `dist/` сюда и отправить коммит в `main`.
GitHub Pages публикует корень ветки `main`. Файл `version.txt` содержит идентификатор сборки.
